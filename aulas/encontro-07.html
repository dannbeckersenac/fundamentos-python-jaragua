  • O if mostrou o aviso. Depois, o programa seguiu com o -2 e calculou um total negativo.
  • Zero é válido: o cliente pode não querer algum produto. Se digitar um número negativo, o programa precisa perguntar de novo.

Quando perguntar de novo?

Com um número negativo, a pergunta volta. Com zero ou mais, o programa segue para os caldos.

Repetir a pergunta com while

exemplo do professor · trecho do pedido.py
pasteis = int(input("Quantos pastéis? "))
while pasteis < 0:
    print("Quantidade inválida.")
    pasteis = int(input("Quantos pastéis? "))
caldos = int(input("Quantos caldos? "))
  • while quer dizer enquanto. O bloco repete enquanto a condição der True.
  • A condição é testada antes de cada volta. Com 2, ela dá False e o programa segue para os caldos.
  • O input dentro do laço lê uma nova quantidade. Se ela for zero ou maior, o laço termina.

for ou while?

forPercorre uma lista. Repete uma vez para cada item e para quando os itens acabam.

for item in comanda:

whileRepete enquanto a condição for verdadeira. Aqui, pergunta até receber uma quantidade válida.

while pasteis < 0:

Prática · 15 minutos

Anotar a comanda até digitar fim

  1. Crie anota_varios.py começando com uma lista vazia.
  2. Peça o primeiro item com input("Item (ou fim): ").
  3. Enquanto o item for diferente de "fim", acrescente-o à lista e pergunte de novo.
  4. Depois do laço, mostre a comanda e quantos itens ela tem.
  5. Teste pastel, caldo, pastel e fim. Confira 3 itens.

Correção: anotar até digitar fim

anota_varios.py
comanda = []
item = input("Item (ou fim): ")
while item != "fim":
    comanda.append(item)
    item = input("Item (ou fim): ")
print(f"Comanda: {comanda}")
print(f"{len(comanda)} itens")
  • A pergunta aparece duas vezes: antes do laço e no fim do bloco, como no exemplo dos pastéis.
  • Ao digitar fim, a condição dá False e o laço termina. Esse texto não entra na lista.

A lanchonete sorteou um número de 1 a 20. Quem acertar ganha um caldo. Quantos palpites o cliente vai dar?

O programa precisa pedir palpites até ele acertar.

Sortear um número com random

Terminal ou IDLE Shell
>>> import random
>>> random.randint(1, 20)
12
>>> random.randint(1, 20)
20
  • import random permite usar os sorteios do módulo random. Um módulo reúne código pronto para usar.
  • random.randint(1, 20) sorteia um inteiro de 1 a 20, com o 1 e o 20 incluídos.
  • No seu computador, o sorteio pode dar outros números.

Encerrar o laço com break

exemplo do professor · adivinha.py
import random
secreto = random.randint(1, 20)
while True:
    palpite = int(input("Seu palpite: "))
    if palpite == secreto:
        print("Acertou! Ganhou um caldo.")
        break
    print("Errou. Tente de novo.")
  • Em while True, a condição é sempre verdadeira. Neste exemplo, o break encerra o laço quando o cliente acerta.
  • Ao passar pelo break, o programa sai do laço sem mostrar Errou. Tente de novo.

Testar o jogo

  1. Crie adivinha.py com o código do exemplo.
  2. Para testar, troque a linha do sorteio por secreto = 12.
  3. Execute e digite 5. Confira Errou. Tente de novo.
  4. Digite 12 e confira Acertou! Ganhou um caldo.

Depois do teste, restaure a linha com random.randint para voltar a sortear.

Prática · 15 minutos

Melhorar o jogo

  1. Depois de cada erro, mostre O número é maior. ou O número é menor.
  2. Conte as tentativas. Ao acertar, mostre quantas foram, como em Acertou em 3 tentativas.
  3. Bônus: limite o jogo a 5 tentativas. Se o cliente errar a quinta, mostre o número sorteado e encerre o laço.

O que vimos hoje

  • while condição: repete o bloco enquanto a condição der True.
  • Algo dentro do laço precisa mudar a condição. Senão o laço não para, e o Ctrl+C interrompe.
  • O break encerra o laço assim que é executado, como no acerto do jogo.
  • import random e random.randint(1, 20) sorteiam um número de 1 a 20.
  • O for percorre os itens da lista. O while testa uma condição a cada volta.
