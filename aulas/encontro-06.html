Retomada das listas e o laço for

Vamos revisar as listas e usar o for para mostrar os itens da comanda.

Etapa 4 · A repetiçãoFundamentos do Python I · Senac Jaraguá do Sul

Retomada · 20 minutos

A comanda da mesa 5

  1. Crie mesa5.py com a lista ["pastel", "caldo", "pastel", "sorvete"].
  2. Mostre o primeiro e o último item da comanda usando o índice.
  3. O cliente desistiu de um pastel. Remova um e mostre como ficou a comanda.
  4. Peça mais um item com input. Se ele já estiver na comanda, mostre Já está na comanda. Caso contrário, acrescente o item.
  5. Mostre quantos itens ficaram. Teste com coxinha: deve aparecer Itens: 4.

Qual pastel o remove tirou?

trecho do mesa5.py
comanda = ["pastel", "caldo", "pastel", "sorvete"]
comanda.remove("pastel")
print(comanda)
Saída
['caldo', 'pastel', 'sorvete']
  • O remove tirou o primeiro pastel da lista. O segundo continua lá.
  • O sorvete estava no índice 3. Depois da remoção, ficou no índice 2.

Como mostrar cada item da comanda numa linha?

Uma mesa pediu 3 itens. Outra pediu 12. Vamos escrever um print para cada um?

Um print para cada posição

mostra.py
comanda = ["pastel", "caldo", "sorvete"]
print(comanda[0])
print(comanda[1])
print(comanda[2])
print(comanda[3])
Saída
pastel
caldo
sorvete
IndexError: list index out of range
  • A lista só tem os índices 0, 1 e 2. Ao tentar acessar o 3, aparece o erro.
  • O mesmo print aparece várias vezes. Só muda a posição.

Como repetir o print para todos os itens da lista?

O fluxograma da repetição

Siga a seta de volta: o programa pega outro item e mostra na tela. Quando a lista acaba, ele sai do laço.

Percorrer a lista com for

percorre.py
comanda = ["pastel", "caldo", "sorvete"]
for item in comanda:
    print("-", item)
print("Fim da comanda")
Saída
- pastel
- caldo
- sorvete
Fim da comanda
  • for item in comanda: repete o bloco uma vez para cada item da lista.
  • A cada volta, item recebe o próximo valor: "pastel", depois "caldo", depois "sorvete".
  • Essa repetição se chama laço. O bloco do laço é o trecho recuado, como no if.

Testar o for

  1. Crie percorre.py na pasta do curso com o código do exemplo.
  2. Execute o arquivo: ▶ no VS Code, F5 no IDLE.
  3. Acrescente "pastel" no fim da lista, sem mexer no for.
  4. Execute de novo e confira a linha - pastel antes de Fim da comanda.
  5. Recue o último print com Tab e execute. Agora Fim da comanda aparece depois de cada item.

O recuo decide o que repete

percorre.py, com o último print recuado
comanda = ["pastel", "caldo", "sorvete"]
for item in comanda:
    print("-", item)
    print("Fim da comanda")
Saída
- pastel
Fim da comanda
- caldo
Fim da comanda
- sorvete
Fim da comanda
  • Com o recuo, print("Fim da comanda") fica dentro do laço e roda a cada item.
  • Para mostrar a mensagem só depois de todos os itens, deixe esse print sem recuo.

Dois erros comuns no for

O que aconteceuA última linha do erro
Faltaram os dois-pontos no fim da linha do forSyntaxError: expected ':'
A linha de dentro do laço ficou sem recuoIndentationError: expected an indented block after 'for' statement on line 2

São os mesmos erros do if. A linha do for termina com : e o bloco fica recuado embaixo dela.

  2. Percorra a lista com for e mostre cada preço com f-string e duas casas decimais.
  3. Depois do laço, mostre quantos preços a lista tem.
  4. Confira a saída: R$ 8.50, R$ 6.00, R$ 7.00, R$ 8.50 e 4 itens.

Quantos pastéis a cozinha precisa fritar?

A comanda tem pastel, caldo, pastel, sorvete e pastel. O len dá 5, porque conta tudo.

Contar com uma variável

exemplo do professor · fritar.py
comanda = ["pastel", "caldo", "pastel", "sorvete", "pastel"]
pasteis = 0
for item in comanda:
    if item == "pastel":
        pasteis = pasteis + 1
print(f"Pastéis para fritar: {pasteis}")
  • pasteis = 0 cria o contador antes do laço.
  • A cada pastel, o contador aumenta 1. O if fica dentro do for, com mais um recuo.
  • O print fica fora do laço e mostra Pastéis para fritar: 3.

Somar os preços item a item

soma.py
precos = [8.5, 6.0, 8.5, 7.0]
total = 0
for preco in precos:
    total = total + preco
print(f"No laço: R$ {total:.2f}")
print(f"Com sum: R$ {sum(precos):.2f}")
Saída
No laço: R$ 30.00
Com sum: R$ 30.00
  • O total começa em zero. A cada volta, recebe mais um preço.
  • O sum também dá R$ 30,00. Com o laço, podemos usar um if para somar só alguns preços.

E se faltar o total = 0?

soma.py, sem o valor inicial
precos = [8.5, 6.0, 8.5, 7.0]
for preco in precos:
    total = total + preco
print(f"Total: R$ {total:.2f}")
Saída
NameError: name 'total' is not defined
  • Na primeira volta, total + preco tenta usar uma variável que ainda não existe.
  • O contador e o acumulador precisam de um valor inicial, antes do for.

E se o print ficar dentro do laço?

soma.py, com o print recuado
precos = [8.5, 6.0, 8.5, 7.0]
total = 0
for preco in precos:
    total = total + preco
    print(f"Total: R$ {total:.2f}")
Saída
Total: R$ 8.50
Total: R$ 14.50
Total: R$ 23.00
Total: R$ 30.00
  • O programa roda, mas mostra uma soma parcial a cada volta.
  • Para mostrar só o total final, coloque o print fora do laço.

Por que o caldo aparece na comanda da cozinha?

O caldo sai pronto do balcão. A cozinha precisa ver só o que ela prepara.

Pular um item com continue

exemplo do professor · cozinha.py
comanda = ["pastel", "caldo", "sorvete"]
print("Para a cozinha:")
for item in comanda:
    if item == "caldo":
        continue
    print("-", item)
Saída
Para a cozinha:
- pastel
- sorvete
  • O continue pula o resto da volta e passa para o próximo item.
  • Quando o item é "caldo", o print de baixo não roda. O laço segue com o sorvete.

O que vimos hoje

  • for item in lista: repete o bloco uma vez para cada item. A variável recebe um item por volta.
  • O bloco do laço é o trecho recuado. O que fica sem recuo roda uma vez, depois do laço.
  • Usamos uma variável para contar itens e outra para somar preços. As duas começam em zero antes do laço.
  • O continue pula o resto da volta e passa para o próximo item.
  • Sem os dois-pontos, SyntaxError. Sem recuo, IndentationError. Sem o valor inicial, NameError.
